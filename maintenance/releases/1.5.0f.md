## RayXDesktop 1.5.0f bêta · D.Synx

- **Plus → Me demander en cas d’erreur de certificat (prochaine connexion)** active le choix interactif de Windows pour la session distante sélectionnée. Utilise **Reconnecter** pour appliquer le réglage à la vue intégrée. Le bouton qui ouvre l’adresse dans Bureau à distance Windows utilise aussi l’option.
- Par défaut, le certificat du poste distant doit être vérifiable par Windows. En mode interactif, Windows demande les identifiants et applique les stratégies du poste.

Extrais tous les fichiers de **RayXDesktop-Windows.zip** dans un même dossier, puis ouvre **RayXDesktop.exe** ou le BAT fourni.
