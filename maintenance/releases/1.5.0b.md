## RayXDesktop 1.5.0b bêta · D.Synx

- **Connexion distante** par adresse IPv4, IPv6 ou nom DNS. Saisis le compte au format **NOMPC\session** ou **DOMAINE\session**. Pour **NOMPC\session**, tu peux laisser l’adresse vide. Le champ de mot de passe est masqué. Lorsqu’il est vide, Windows demande le mot de passe.
- **Importer un .rdp** lit les paramètres d’un bureau direct. Un mot de passe protégé par Windows peut être utilisé pour une tentative si le profil Windows courant peut le lire. La vérification de l’identité du poste distant reste obligatoire.
- **Miniatures de session** dans le bandeau. Lorsque tu changes de vue, RayXDesktop actualise la miniature de la session quittée. **Plus → Ouvrir le dossier des miniatures** ouvre le dossier qui contient les PNG de la fenêtre courante.

Extrais tout le ZIP dans un dossier. Le BAT permet de démarrer le bureau local. Le ZIP public est non signé. Le fichier SHA-256 et le guide en français accompagnent la bêta.
