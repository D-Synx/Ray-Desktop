## RayXDesktop 1.5.0j bêta · D.Synx

- Sur une connexion RDP avec authentification stricte, **Enregistrer ce mot de passe sur ce PC** chiffre le mot de passe avec Windows DPAPI après une connexion réussie. Le secret chiffré est conservé dans `data.ini` pour le profil Windows courant.
- **Plus → Reconnecter au démarrage** choisit la session distante à ouvrir au prochain lancement. En mode avec avertissement de certificat, Windows conserve l’invite d’identification.
- **Plus → Enregistrer ou modifier le mot de passe…** et **Oublier le mot de passe enregistré** gèrent les identifiants d’une session enregistrée.

Extrais tous les fichiers de **RayXDesktop-Windows.zip** dans un dossier où tu peux écrire. Conserve `data.ini` lors de la mise à jour.
