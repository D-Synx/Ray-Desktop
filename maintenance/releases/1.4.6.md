## RayXDesktop 1.4.6 · D.Synx

RayXDesktop ouvre une session enfant Windows dans une fenêtre. Cette version propose une interface en français ou en anglais, une barre affichée dès l’ouverture, le bouton **Reconnecter**, le transfert de fichiers vers le Bureau de la session ouverte et une icône de moniteur pour rouvrir la barre réduite.

### Démarrage

1. Télécharge **RayXDesktop-Windows.zip** dans **Assets** puis extrais tous les fichiers dans le même dossier.
2. Lance **RayXDesktop.exe** pour ouvrir le bureau avec le compte Windows actuel. Pour utiliser un autre compte local autorisé, ouvre **RayXDesktop.bat** dans le Bloc-notes.
3. Dans ta copie du BAT, remplace le compte d’exemple **.\Admin** si nécessaire et remplace **PASSW_WORD!** par ton mot de passe. Enregistre puis double-clique sur le BAT.

Le BAT retrouve l’exécutable dans son propre dossier. Le ZIP contient aussi **README.fr.md**, avec les options de connexion, l’usage de la barre et les étapes de configuration. Le BAT distribué contient uniquement des valeurs d’exemple. Un BAT personnalisé contient son mot de passe en clair et doit rester privé.
