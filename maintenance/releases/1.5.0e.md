## RayXDesktop 1.5.0e bêta · D.Synx

- Le presse-papiers RDP des connexions distantes intégrées est activé pour le copier-coller de texte dans les deux sens. Les stratégies de redirection Windows s’appliquent.
- **Plus → Partager le presse-papiers (prochaine connexion)** permet de régler le partage pour la session distante sélectionnée. Le réglage prend effet à la reconnexion.

Extrais tous les fichiers de **RayXDesktop-Windows.zip** dans un même dossier, puis ouvre **RayXDesktop.exe** ou le BAT fourni.
