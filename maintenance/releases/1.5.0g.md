## RayXDesktop 1.5.0g bêta · D.Synx

- Après une déconnexion RDP `0x00000107` sans cause précise avant l’ouverture de session, **Réessayer avec l’avertissement de certificat** apparaît dans la vue concernée. Le mode interactif de Windows s’applique à cette tentative après un clic sur le bouton.
- Windows présente l’avertissement et demande les identifiants selon sa stratégie. Le réglage **Me demander en cas d’erreur de certificat** reste disponible dans **Plus** pour les connexions suivantes de la session sélectionnée.

Extrais tous les fichiers de **RayXDesktop-Windows.zip** dans un même dossier, puis ouvre **RayXDesktop.exe** ou le BAT fourni.
