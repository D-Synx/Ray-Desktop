## RayXDesktop 1.4.7 bêta · D.Synx

Le lanceur portable **RayXDesktop.bat** contient uniquement le compte cible. RayXDesktop demande son mot de passe à l’ouverture et à chaque nouvelle tentative manuelle. Ouvrir directement **RayXDesktop.exe** conserve le mode utilisant le compte Windows courant.

1. Télécharge **RayXDesktop-Windows.zip** dans **Assets**, puis extrais tous les fichiers dans le même dossier.
2. Dans le BAT, remplace **.\Admin** si le compte local porte un autre nom.
3. Lance le BAT et saisis le mot de passe dans RayXDesktop. La barre conserve les commandes d’affichage, de transfert de fichiers et de reconnexion.

Le fichier **RayXDesktop-Windows.zip.sha256** permet de vérifier l’intégrité du téléchargement. Le ZIP de cette préversion est **non signé**. Le [guide de la bêta](https://github.com/D-Synx/Ray-Desktop/blob/ray-desktop-maintenance/maintenance/README.fr.md) contient la procédure Authenticode à utiliser avec un certificat approuvé et la recette à exécuter sur trois postes Windows.
